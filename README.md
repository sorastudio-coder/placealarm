# PlaceAlarm

登録した場所への到着を検知し、アラームでお知らせするiOSアプリです。

駅の乗り過ごし防止や、自宅など到着時に思い出したいことのために、
登録した目的地への到着をサポートします。

## 主な機能

- 登録した場所への到着を自動検知
- 登録した場所からの出発を検知
- 到着時にアラームでお知らせ
- 場所の追加・編集・削除
- 場所名・住所・メモによる検索
- 現在地を利用した場所の登録
- 登録した場所の位置情報・到着範囲の確認
- 位置情報の検知精度設定

## Premium

Premiumでは、無料版の制限を解除して、
より多くの場所を登録して利用できます。

- 場所登録数の制限解除
- アラーム利用回数の制限解除

## プライバシー

位置情報は、登録した場所への到着・出発の検知や
アラーム機能を提供するために利用します。

登録した場所などのデータは、アプリの機能を提供するために
利用者の端末上で管理されます。

詳しくは、[プライバシーポリシー](privacy.html)をご覧ください。
